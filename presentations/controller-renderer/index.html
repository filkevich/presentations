Pros & Cons

    Pros

    - Clear separation: business logic vs. presentation

    - Consistent structure across the codebase

    Cons

    - More files for very small components

FAQs

Can renderer have local state?

No. Even for view-only concerns, keep state in the Controller.

Can we use Intl hooks in the Renderer?

Yes — use `useIntl()` for messages and formatting.

Can we skip Controller for UI-only components?

If a component is truly dumb and has no controller, you don’t need to split.
However, keep the naming convention (ComponentNameRenderer) so adding a Controller later is frictionless.
